# Mapa Interativo de Extremoz

Site para apresentar pontos turísticos, serviços e pequenos comércios de Extremoz/RN em um mapa interativo.

## Arquivos

- `index.html`: estrutura da página.
- `styles.css`: estilos e layout responsivo.
- `script.js`: dados iniciais e interações do mapa.
- `V10 - JOÃO LUCAS, LUCAS CORCINO, MIGUEL VINICIUS.md`: documento do projeto.

## Executar

Abra `index.html` em um navegador. O mapa usa Leaflet, mapas-base do OpenStreetMap e o limite municipal obtido pela API de malhas do IBGE, portanto precisa de conexão com a internet.

O cadastro atual contém 14 pontos iniciais. As coordenadas ainda precisam ser conferidas antes da publicação como dados validados.
